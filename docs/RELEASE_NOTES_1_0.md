# 대국 1.0 출시 노트

대국 1.0은 브라우저와 iOS용 첫 정식 출시 기준선이다.

## 주요 기능

- 9×9 보드의 흑·백 대국과 왕, 장군, 외교관, 마법사 규칙
- 다섯 단계 AI 대국과 흑·백 진영 선택
- 초심자용 연속 튜토리얼과 챌린지 흐름
- 방 생성, 가위바위보 선공 결정과 재대국을 지원하는 온라인 PvP
- 한국어·영어 UI, 배경음악·효과음과 30초 턴 타이머
- 대국 결과, 되돌리기, 기권, 시간 초과와 둘 곳 없음 종료 처리

## 1.0 정리 사항

- 엔진, UI, 서버와 프로토콜의 진영 ID를 `black`/`white`로 통일
- WebSocket 프로토콜 버전 3 및 JSONL 대국 기록 스키마 2 적용
- 스키마 1의 역사적 `red`/`blue` 기록을 읽는 입력 마이그레이션 제공
- 실제 두 클라이언트 온라인 흐름과 숨은 정보 차단 통합 테스트 추가
- 오래된 소스 문자열 결합 테스트, 미리보기 파일, 중복 원고와 미사용 에셋 제거
- 온라인 정보 배지, 한국어 결과 사유와 튜토리얼 연출 테스트의 타이밍 회귀 수정

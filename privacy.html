1. 운영자

DAEGUK은 캐나다 소재의 Boahs Park가 TZIB Studio라는 브랜드로 운영합니다. 개인정보 관련 문의는 support@tzib.studio로 보내주세요.

2. 처리하는 정보

  • 온라인 대국 최초 이용 시 자동 생성되는 익명 인증 사용자 ID와 인증 세션
  • 내부 플레이어 ID, 20자리 공개 게임 ID, 자동 생성 게스트 닉네임과 계정 생성 시각
  • 온라인 대국 중 메모리에서 처리되는 방, 진영, 보드, 차례, 제한 시간과 연결 상태
  • 서비스 보안과 장애 대응에 필요한 IP 주소, 요청 시각 및 기술적 로그가 호스팅·보안 제공자에 의해 처리될 수 있습니다.

이메일, 전화번호, 실명, 위치, 연락처, 사진, 마이크 또는 카메라 정보는 게임 계정 생성 과정에서 요청하지 않습니다.

3. 이용 목적

정보는 게스트 인증, 동일한 공개 게임 ID 유지, 온라인 매칭과 경기 재접속, 부정 가입 방지, 보안 및 장애 대응을 위해서만 사용합니다. 광고 또는 사용자 추적에 사용하지 않습니다.

4. 기기에만 저장되는 정보

언어·음향·AI 타이머 설정, 튜토리얼·챌린지 진행 상황, PvE 진단 기록과 온라인 복귀표는 기기에만 저장되며 서버 계정과 연결되지 않습니다. 온라인 복귀표에는 인증 토큰이 포함되지 않습니다.

5. 서비스 제공자와 국외 처리

Supabase는 익명 인증, Cloudflare Turnstile은 자동화 방지, Render는 게임·인증 서버, Vercel은 웹 앱과 인증 프록시를 제공합니다. 이 과정에서 정보가 캐나다 외 국가의 시스템에서 처리될 수 있으며 각 제공자는 계약과 자체 개인정보 보호 조건에 따라 정보를 보호합니다.

6. 보관과 삭제

게스트 계정 정보는 사용자가 계정을 삭제할 때까지 보관합니다. 온라인 경기 상태는 서버 메모리에서만 처리되며 방 종료 또는 서버 재시작 시 사라집니다. 법률상 보존이 필요한 경우를 제외하고 계정 삭제가 완료되면 익명 인증 사용자와 서버의 플레이어 매핑을 삭제합니다.

7. 계정 및 개인정보 선택

앱의 설정 → 계정 삭제에서 게스트 계정과 온라인 게임 ID를 영구 삭제할 수 있습니다. 웹 인증 쿠키 또는 iOS Keychain 세션과 온라인 복귀표도 함께 제거됩니다. 기기에만 저장된 진행 상황과 설정은 유지되며, 앱 삭제 또는 브라우저 사이트 데이터 삭제로 제거할 수 있습니다.

보유 정보의 확인·정정, 삭제 또는 개인정보 처리에 대한 이의 제기는 support@tzib.studio로 요청할 수 있습니다.

8. 아동과 전연령 이용

DAEGUK은 특정 아동 연령층만을 대상으로 하지 않는 전연령 게임이며, 생년월일이나 연락처를 요청하지 않습니다. 보호자는 아동의 게스트 계정 삭제나 개인정보 관련 문의를 위 이메일로 요청할 수 있습니다.

9. 보안과 변경

인증 토큰을 웹의 HttpOnly·Secure 쿠키 또는 iOS의 기기 전용 Keychain에 저장하고 접근을 제한합니다. 방침이 변경되면 이 페이지의 시행일을 갱신하며, 중요한 변경은 앱 또는 지원 페이지에서 안내합니다.

1. Operator

DAEGUK is operated in Canada by Boahs Park under the TZIB Studio brand. Contact support@tzib.studio with privacy questions.

2. Information we process

  • An anonymous authentication user ID and session created when online play is first used
  • An internal player ID, a 20-character public game ID, an automatically generated guest nickname, and account creation time
  • Room, side, board, turn, timer, and connection state processed in memory during an online match
  • IP address, request time, and technical logs may be processed by hosting and security providers for service security and incident response.

We do not request an email address, phone number, real name, location, contacts, photos, microphone data, or camera data when creating a game account.

3. Purposes

We use this information only for guest authentication, maintaining a stable public game ID, online matchmaking and reconnection, preventing automated sign-ups, security, and incident response. We do not use it for advertising or user tracking.

4. Information stored only on your device

Language, sound and AI timer settings, tutorial and challenge progress, PvE diagnostic records, and the online resume ticket remain on your device and are not linked to the server account. The resume ticket contains no authentication token.

5. Service providers and international processing

Supabase provides anonymous authentication, Cloudflare Turnstile prevents automated abuse, Render hosts the game and authentication server, and Vercel hosts the web app and authentication proxy. Information may be processed on systems outside Canada, subject to the providers’ contractual and privacy protections.

6. Retention and deletion

Guest account information is kept until the user deletes the account. Online match state is processed only in server memory and disappears when the room ends or the server restarts. Unless retention is required by law, completing account deletion removes the anonymous Auth user and the server player mapping.

7. Account and privacy choices

You can permanently delete the guest account and online game ID under Settings → Delete Account. The web authentication cookie or iOS Keychain session and online resume ticket are also removed. Device-only progress and settings remain and can be removed by deleting the app or clearing the browser’s site data.

To request access, correction, deletion, or raise a privacy concern, email support@tzib.studio.

8. Children and general audiences

DAEGUK is a general-audience game that is not directed exclusively to a particular child age group. We do not request a date of birth or contact details. A parent or guardian may request deletion of a child’s guest account or contact us about privacy using the address above.

9. Security and changes

Authentication tokens are restricted to an HttpOnly and Secure web cookie or the device-only iOS Keychain. If this policy changes, we will update the effective date and provide notice in the app or on the support page for material changes.

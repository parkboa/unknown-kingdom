Updated: 2026-07-17

Note
- UI side names: Black / White
- Internal code side IDs: red = Black, blue = White
- This file collects player-facing scripts by scene for copy review.

UI Copy Rules
- Buttons: 1-2 words.
- English button examples: Back, Deploy, Close.
- Descriptions: keep within 40 characters when possible.
- Descriptions: start with a verb.
- English descriptions: use sentence-ending periods.
- English buttons: do not use sentence-ending periods.
- Korean copy: use the polite "~하세요" style consistently.
- Do not rewrite current scripts automatically; apply these rules during future copy refinement.
